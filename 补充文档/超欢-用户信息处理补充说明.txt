一、小程序概况

超欢是一款纯本机运行的效率工具与个人作品集。小程序不含账号体系、不提供登录、不接入后端服务、不发起网络请求，全部计算与图片处理均在本机完成。

1. 名称：超欢（项目代号 chaohuan-toolbox）
2. 形态：4个主页面（工具、收藏、我的、隐私与说明）、20个工具、11个作品条目
3. 运行模式：离线可用；除首次查看作品时由微信按需下载分包外，小程序自身不发起网络请求
4. 账号：无注册、无登录、无用户ID、无会员与付费功能
5. 联系方式：56967916@qq.com


二、处理的用户信息

依据《个人信息保护法》的最小必要原则，本小程序处理下列三类用户信息，且全部由用户主动操作触发，不存在后台自动采集；此外仅读取用于界面适配的运行环境参数（见2.1）。

（一）选中的照片或视频信息
触发场景：图片压缩、图片取色、九宫格切图；用户点击“选择图片”后从相册选择。
调用接口：wx.chooseMedia（count: 1、mediaType: ["image"]、sourceType: ["album"]）。
处理方式：仅读取用户当次选择的一张图片，在本机内存与系统临时文件中处理；不上传、不写入小程序本地存储、不建立相册索引，中间文件在处理结束后删除。

（二）相册（仅写入）权限
触发场景：保存压缩图、九宫格切片、二维码、作品图集、个人名片。
调用接口：wx.saveImageToPhotosAlbum（scope.writePhotosAlbum）。
处理方式：仅将用户指定的图片写入系统相册；不读取、不扫描、不遍历相册内容。

（三）剪切板
触发场景：用户点击“复制”时，如复制计算结果、金额大写、JSON文本、联系邮箱。
调用接口：wx.setClipboardData。
处理方式：仅写入用户主动复制的文本；不读取剪贴板内容，代码中无wx.getClipboardData调用。

2.1 运行环境参数
为实现外观跟随系统、响应式布局与画布清晰度适配，小程序只读取以下运行环境字段：
1. wx.getWindowInfo：windowWidth、windowHeight、statusBarHeight、pixelRatio，用于页面布局、导航栏对齐与Canvas分辨率计算。
2. wx.getAppBaseInfo：theme，即系统深浅色，仅用于外观“跟随系统”模式。
3. wx.getDeviceInfo：platform，仅用于判断当前是否运行在开发者工具；基础库不支持该接口时回退wx.getSystemInfoSync，同样只读取platform。
wx.getWindowInfo 与 wx.getDeviceInfo 只在页面或组件初始化、画布渲染时按需读取，不做轮询；系统深浅色在启动时读取一次，并通过 wx.onThemeChange 跟随系统变化更新。
上述字段本身不包含设备型号、品牌、系统版本、序列号或任何设备唯一标识，不写入本地存储，不上传，也不与任何用户身份关联。
另外，为对齐微信右上角胶囊按钮，小程序会读取胶囊位置（wx.getMenuButtonBoundingClientRect），仅用于导航栏布局，不含设备或用户信息。
本小程序不采集IMEI、OAID、IDFA、MAC地址、Android ID等设备标识，也不采集通讯录、位置、麦克风、摄像头、日历、蓝牙、传感器、订单、发票、身份证件、微信运动等信息。


三、不处理的信息

为避免歧义，本小程序明确不处理以下信息：

1. 身份与账号：姓名、微信昵称、微信头像、手机号、邮箱（邮箱仅作为开发者联系方式对外公示，不从小程序内收集）、身份证号码、实名信息、登录凭证。
2. 位置与设备：精确或模糊位置、设备唯一标识、剪贴板内容、通讯录、通话记录。
3. 媒体与传感器：摄像头画面、麦克风录音、相册全量内容、日历、蓝牙、加速传感器、磁场传感器、方向传感器、陀螺仪传感器。
4. 业务与内容：订单信息、发票信息、发布内容、所关注账号、操作日志、微信运动数据、车牌号。


四、权限申请与撤回

本小程序仅申请一项系统权限，且只在用户主动保存图片时触发。

权限名称：保存到相册（scope.writePhotosAlbum）。
触发时机：用户点击“保存到相册”时申请。
未授权的影响：仅无法保存图片，其余工具与浏览功能不受影响。
撤回路径：微信 → 设置 → 小程序 → 超欢 → 权限管理 → 关闭“保存到相册”。

本小程序不申请位置、通讯录、相机、麦克风、日历、蓝牙、运动数据等权限；撤回相册权限后，再次保存时会引导用户前往设置页重新开启或放弃保存。


五、本机数据与存储

为记住常用工具、收藏、外观与定位本机异常，本小程序使用微信本地存储保存以下轻量数据。数据仅保存在用户设备内，不离开设备、不上传服务器。

1. tbx:recent：最近使用的工具id，上限12项，不含个人信息。
2. tbx:favorites：收藏的工具id，上限100项，不含个人信息。
3. tbx:legacy-tip-home：旧简历迁移提示的关闭状态，上限1项，不含个人信息。
4. gallery.works.favorites：作品收藏的作品id，上限200项，不含个人信息。
5. gallery.theme.mode：外观模式（auto / light / dark），上限1项，不含个人信息。
6. diag:errors.v1：错误诊断日志，含发生时间、错误类型、摘要、堆栈、页面路径，上限20条，不含输入内容。
7. app:storage.version：本地数据版本号，仅用于升级迁移，上限1项，不含个人信息。

本小程序不保存任何输入值、图片、计算结果或搜索词，也不保存通讯录、位置等敏感信息。
清除方式：我的 → 清空工具数据（仅清除tbx:前缀数据）；微信 → 设置 → 通用 → 存储空间 → 小程序缓存；卸载小程序或清除小程序数据后，上述本地数据全部删除。


六、第三方SDK与对外提供

1. 不接入任何会收集用户信息的第三方SDK：无广告、无统计分析、无推送、无地图、无支付、无社交分享SDK；开源基础库（如MobX、Lottie、Remix Icon）仅用于本地状态管理与界面渲染，不采集、不上传数据。
2. 不向任何第三方共享、转让或公开披露用户信息。
3. 不进行数据出境，不存在境外接收方。
4. 不进行用户画像、自动化决策或定向推荐。
5. 作品图集位于微信分包：首次查看时由微信客户端按需下载，属于微信分包机制，不是本小程序上传数据。


七、信息安全措施

1. 全链路本机处理：无网络请求接口、无服务器、无数据库，计算结果仅存在于本机内存。
2. 图片处理结束后删除中间临时文件，包括九宫格切片与压缩中间产物。
3. 诊断日志仅存本机，环形保留最近20条，单条消息截断500字符、堆栈截断1000字符。
4. 权限最小化：相册仅写入、剪贴板仅写入；不申请相机、麦克风等权限，也不扫描相册列表。
5. 代码与资源中不含服务端密钥或第三方凭证。


八、用户权利

依据《个人信息保护法》，用户对自身信息享有查阅、复制、更正、删除、撤回同意等权利。由于本小程序不在服务器保存任何用户信息，相关权利主要体现为清除本机数据与撤回授权。

1. 查阅、复制、更正、删除：发送邮件至56967916@qq.com，说明需求与相关信息，开发者将在15个工作日内核查并处理。
2. 撤回同意：通过微信“设置 → 小程序 → 超欢 → 权限管理”关闭“保存到相册”。
3. 注销账号：本小程序无账号体系，无需注销；卸载小程序或清除小程序数据即可删除全部本地数据。
4. 投诉与建议：可通过上述邮箱联系，或使用微信客户端提供的小程序投诉入口。


九、未成年人保护

本小程序不面向14周岁以下未成年人定向收集信息，也不提供社交、付费、抽奖或虚拟支付功能。若监护人发现未成年人的信息被处理，可通过上述邮箱联系开发者，开发者将在核实后删除相关数据。
