一、小程序概况

超欢是一款以本机计算为主的效率工具与个人作品集。小程序不含账号体系、不提供登录、不接入自建后端；除「全息气象」按需向高德开放平台请求天气数据外，其余功能不发起网络请求，计算与图片处理均在本机完成。

1. 名称：超欢（项目代号 chaohuan-toolbox）
2. 形态：主包 5 个页面（工具、收藏、我的、隐私与说明、组件样板间）、26 个工具、11 个作品条目、1 个全息专注页
3. 运行模式：除在线气象外可离线使用；工具页、专注页、数据驾驶舱、简历与作品图集按微信分包机制按需下载
4. 账号：无注册、无登录、无用户 ID、无会员与付费功能
5. 联系方式：56967916@qq.com


二、处理的用户信息

依据《个人信息保护法》的最小必要原则，本小程序仅在下列场景、且由用户主动操作触发时处理信息；不存在后台自动采集。首次调用定位、相册等敏感能力前，统一通过 wx.requirePrivacyAuthorize 获取微信《用户隐私保护指引》授权；此外仅读取用于界面适配的运行环境参数（见 2.9）。

2.1 位置信息（城市级模糊定位）

触发场景：用户打开「全息气象」，且同意微信《用户隐私保护指引》后。
调用接口：wx.getFuzzyLocation（type: gcj02）。
处理目的：获取城市级模糊位置，向高德逆地理编码换取 6 位 adcode，用于请求当地天气与估算日出日落。
处理方式：不申请精确 getLocation；经纬度仅用于当次逆地理与本地日出日落计算，城市列表只保存城市级中心点（来自模糊定位、IP 区域中心或高德行政区数据），不保存设备精确坐标；不上传至自建服务器。
降级策略：拒绝授权、接口不可用或逆地理失败时，自动改用高德 IP 定位；IP 定位仍失败、为局域网、非法或高德无法识别的 IP 时，转为手动搜索城市。
权限声明：app.json 中 requiredPrivateInfos 仅声明 getFuzzyLocation；代码中不调用 wx.getLocation，不申请精确位置。首次调用前统一通过 wx.requirePrivacyAuthorize 获取微信《用户隐私保护指引》授权。

2.2 选中的图片

触发场景：图片压缩、图片取色、九宫格切图、水印工作台；用户点击「选择图片」后从相册选择。
调用接口：wx.chooseMedia（count: 1、mediaType: ["image"]、sourceType: ["album"]）。
处理方式：仅读取用户当次选择的一张图片，在本机内存与系统临时文件中处理；不上传、不写入小程序本地存储、不建立相册索引，中间文件在页面退出或重新选择时删除；若经快捷管道流转，图片会写入小程序临时目录，并在管道结束或下次启动时回收。
说明：sourceType 仅 album，不调用相机，不申请摄像头权限。

2.3 相册（仅写入）权限

触发场景：保存压缩图、九宫格切片、二维码、水印图、作品图集、个人名片或分享海报。
调用接口：wx.saveImageToPhotosAlbum（scope.writePhotosAlbum）。
处理方式：仅将用户指定的图片写入系统相册；不读取、不扫描、不遍历相册内容；拒绝授权时仅无法保存，不影响其他功能。

2.4 剪切板

写入：用户点击「复制」时调用 wx.setClipboardData，仅写入当次结果、邮箱或备份码。
读取：仅在「设置 → Sliced Transport」点击「从剪贴板追加」时调用 wx.getClipboardData 读取一次，用于跨端传输备份码。
处理方式：不后台读取、不监听剪贴板变化、不保存剪贴板内容。
授权：剪贴板读写均为微信隐私接口，首次使用需用户同意《用户隐私保护指引》；拒绝授权时不读取、不写入，仅提示授权后再试。

2.5 设备姿态（运动传感器）

触发场景：组件样板间的全息视差；全息专注的「翻转黑屏」（手机面朝下时自动黑屏）。
调用接口：wx.startDeviceMotionListening / wx.onDeviceMotionChange / wx.stopDeviceMotionListening。
触发条件：仅页面可见；视差在开启动效时监听；翻转黑屏仅在专注进行中且用户开启该开关时监听。
处理方式：设备姿态仅用于本地视觉阻尼或判断是否面朝下；离开页面、结束专注或组件销毁时立即停止并解绑；不保存原始传感器数据、不上传。
关闭方式：翻转黑屏可在专注设置关闭；视差可在「设置 → 动画强度」选择「省电」关闭。

2.6 屏幕亮度与常亮

触发场景：进入全息专注并开始计时。
调用接口：wx.getScreenBrightness、wx.setScreenBrightness、wx.setKeepScreenOn。
处理方式：进入专注时先读取当前屏幕亮度并记录原值，再临时调暗、保持屏幕常亮；退出页面、结束或放弃专注时恢复原亮度并关闭常亮；亮度原值与恢复标记仅存本机。
说明：不读取屏幕内容、不截屏、不录屏。

2.7 后台音频

触发场景：全息专注开启提示音且进入计时。
调用接口：wx.getBackgroundAudioManager、wx.getFileSystemManager。
处理方式：运行时生成 1 秒低振幅 WAV（focus-bgm-v1.wav，约 16KB）写入小程序本地文件目录并循环播放，用于避免锁屏后计时被系统中断；不录音、不申请麦克风、不播放任何第三方音频文件。
声明：app.json 中 requiredBackgroundModes 仅声明 audio。

2.8 振动与界面音效

触发场景：按钮点击、长按、完成或错误提示。
调用接口：wx.vibrateShort、wx.createInnerAudioContext。
处理方式：振动仅调用系统短振动；音效仅播放内嵌 WAV（首次预加载写入本地文件目录），不录音、不采集声音；可在「设置 → 物理震动」与「设置 → 系统音效」关闭。

2.9 运行环境参数

为实现外观跟随系统、响应式布局与画布清晰度适配，小程序只读取以下运行环境字段：
1. wx.getWindowInfo：windowWidth、windowHeight、statusBarHeight、pixelRatio 与 safeArea.bottom，用于页面布局、导航栏对齐、底部安全区与 Canvas 分辨率计算。
2. wx.getAppBaseInfo：theme，即系统深浅色，仅用于外观「跟随系统」模式。
3. wx.getDeviceInfo：platform，仅用于判断当前是否运行在开发者工具；基础库不支持该接口时回退 wx.getSystemInfoSync，同样只读取 platform。
4. wx.getMenuButtonBoundingClientRect：胶囊按钮位置，仅用于导航栏布局。
5. wx.getEnterOptionsSync：仅读取启动 query 中的 tool 参数，用于工具深链跳转；非法参数直接丢弃，不保存、不上传。
上述字段不包含设备型号、品牌、系统版本、序列号或任何设备唯一标识，不写入本地存储、不上传，也不与任何用户身份关联。系统深浅色在启动时读取一次，并通过 wx.onThemeChange 跟随系统变化更新。本小程序不采集 IMEI、OAID、IDFA、MAC 地址、Android ID 等设备标识。


三、网络请求与第三方服务

1. 唯一第三方数据服务：高德开放平台 Web 服务 API（https://restapi.amap.com）。
2. 请求端点与用途：
   - /v3/weather/weatherInfo（extensions=base）：天气实况；
   - /v3/weather/weatherInfo（extensions=all）：4 天预报；
   - /v3/geocode/regeo：模糊经纬度转城市与 adcode；
   - /v3/ip：模糊定位不可用时的城市级 IP 定位；
   - /v3/config/district：城市搜索。
3. 请求参数：adcode、模糊经纬度、城市搜索关键词、extensions 与高德 Web服务 Key；不包含微信昵称、头像、手机号、OpenID/UnionID、通讯录、相册内容、剪贴板或其他工具的输入内容。
4. 传输安全：全部为 HTTPS；小程序后台已配置 request 合法域名 https://restapi.amap.com；不存在其他请求域名。
5. 高德可能按其隐私政策处理请求 IP、调用时间、模糊经纬度、城市编码与搜索关键词；本程序不向其发送用户身份信息。高德隐私政策：https://lbs.amap.com/pages/privacy/
6. 不接入广告、统计分析、推送、高德地图/定位 SDK、支付、社交分享 SDK（仅使用高德 Web 服务 REST API）；除全息气象按需向高德发送城市编码、模糊经纬度或搜索关键词外，不向任何第三方共享、转让或公开披露用户信息；不进行数据出境，不存在境外接收方；不进行用户画像、广告定向或对用户权益有重大影响的自动化决策。
7. 全息气象的 Key 为仅具 Web 服务查询权限的 Key，通过构建期本地配置注入，不写入公开仓库；如 Key 泄露可在高德控制台随时停用或更换。


四、不处理的信息

为避免歧义，本小程序明确不处理以下信息：

1. 身份与账号：姓名、微信昵称、微信头像、手机号、邮箱（邮箱仅作为开发者联系方式对外公示，不从小程序内收集）、身份证号码、实名信息、登录凭证、OpenID/UnionID。
2. 设备标识：IMEI、OAID、IDFA、MAC 地址、Android ID、序列号等任何设备唯一标识。
3. 媒体与传感器原始数据：摄像头画面、麦克风录音、相册全量内容、通讯录、通话记录、日历、蓝牙、健康数据、微信运动步数；设备姿态仅用于本地视觉阻尼，不留存原始数据。
4. 业务与内容：订单信息、发票信息、发布内容、所关注账号、操作日志、车牌号。
5. 剪贴板历史：仅在用户点击「从剪贴板追加」时读取一次，不保留、不统计。


五、权限申请与撤回

本小程序涉及的敏感能力与权限如下：

1. 位置信息（城市级模糊定位）：仅在全息气象中申请；未授权时自动降级为 IP 定位或手动选城，不影响其他工具。
2. 保存到相册（scope.writePhotosAlbum）：仅在用户点击保存时申请；未授权时仅无法保存图片。
3. 剪切板读取：仅在用户点击「从剪贴板追加」时读取一次，用于导入备份码，不后台读取、不保存剪贴板内容。
4. 设备姿态：全息视差在支持视差的页面开启；翻转黑屏仅在专注进行中且开关开启时监听；均可在对应设置中关闭。
5. 后台音频：仅在全息专注计时期间使用，可随时关闭提示音或退出专注。

撤回路径：微信 → 设置 → 小程序 → 超欢 → 权限管理，关闭「位置信息」或「保存到相册」；隐私授权可在小程序内重新触发，或在微信「设置 → 隐私 → 授权管理」中管理。
撤回影响：撤回位置后气象站改用 IP 定位或手动选城；撤回相册后再次保存会引导前往设置页重新开启或放弃保存；其余工具不受影响。


六、本机数据与存储

为记住常用工具、天气城市、专注记录并定位本机异常，本小程序使用微信本地存储与本地文件目录保存以下轻量数据。数据仅保存在用户设备内，不离开设备、不上传服务器。

（一）tbx: 工具命名空间
1. tbx:recent：最近使用的工具 id，上限 12 项。
2. tbx:recent.at：最近使用时间戳，仅用于自动清理。
3. tbx:favorites：收藏的工具 id，上限 100 项。
4. tbx:usage：累计打开工具的次数（单个整数），仅用于首页数字看板；清空工具数据时一并删除。
5. tbx:history：本机计算轨迹摘要，上限 100 条；含工具名称、时间、输入/输出摘要与主题快照。
6. tbx:workflow.pipes：快捷管道 A → B 的工具配对与成功流转次数，上限 6 条。
7. tbx:workflow.garbage：待回收的临时图片路径队列，仅存路径，不含图片内容。
8. tbx:prefs：旧版偏好，仅在升级时读取，不再写入。
9. tbx:ack.finance.v1 / tbx:ack.health.v1：金融、健康提示的确认状态。
10. tbx:legacy-tip / tbx:legacy-tip-home：旧收藏、旧简历迁移提示的关闭状态。
11. tbx:searchHistory：本机搜索历史，上限 8 条；仅含搜索词与时间，清空搜索历史即删除。
12. tbx:helpBannerDismissed：首页帮助横幅的关闭状态（布尔值），仅用于避免重复提示。

（二）app: 全局偏好
1. app:prefs.v1：震动、音效、光效、动画与自动清理天数。
2. app:prefs.v0：旧版偏好，仅在升级时读取一次。
3. app:storage.version：本地数据版本号，仅用于升级迁移。
4. hasPendingUpdate：更新提示红点标记（布尔值，无命名空间），仅用于设置页展示「新版本已就绪」，更新生效或确认无更新后自动清除。

（三）gallery. 外观与作品
1. gallery.theme.mode：白昼 / 夜航 / 跟随系统。
2. gallery.works.favorites：作品收藏 id，上限 200 项。
3. gallery.glass.meta：Spatial Glass 界面元数据，含版本号、迁移时间、外观模式与环境预设，不含身份信息或设备标识。

（四）weather: 气象缓存
1. weather:cities:v1：城市列表，上限 5 个；含城市名、省份、6 位 adcode、城市级中心点（来自模糊定位、IP 区域中心或高德行政区数据）、来源标记（模糊 / IP / 手动）与更新时间。
2. weather:current:v1：当前选中城市的 adcode。
3. weather:live:v1:{adcode}：实况缓存，15 分钟过期；含官方天气字段、城市名称/编码、发布时间与缓存时间。
4. weather:forecast:v1:{adcode}：4 天预报缓存，30 分钟过期；含官方预报字段、城市名称/编码、发布时间与缓存时间。
5. weather:fail:v1:{adcode}:{kind}：请求失败负缓存，60 秒过期，只含失败时间戳与版本号。
6. weather:ambient:v1、weather:lab:v1、weather:manual-refresh:v1：环境音开关、实验开关与上次手动刷新时间。

（五）focus: 全息专注
1. focus:session:v1：当前或中断的专注会话，含用户可选标签、阶段、轮次与音频偏好。
2. focus:prefs:v1：专注偏好，含三条环境音轨、主增益、BGM 与翻转检测开关。
3. focus:ledger:v1：专注记录，上限 50 条；每条含用户可选标签、起止时间、专注时长、中断次数、等级与校验签名。
4. focus:stats:v1：累计统计。
5. focus:key:v1：本机校验密钥。
6. focus:brightness:v1：亮度恢复标记，含原始亮度值，用于异常退出后恢复屏幕亮度。
上述数据只存本机、不上传；会话、记录与统计带本机签名用于防篡改，偏好与亮度标记不带签名，密钥本身用于签名。可在「设置 → 存储与数据 → 清空专注数据」删除。

（六）cyber: 时间旅行与热备
1. cyber:auto:v1：自动快照，最多 5 个。
2. cyber:hot:v1：手动热备，最多 3 个。
3. cyber:pilot:v1：自动任务开关与表达式。
快照含当时的收藏、最近使用、打开次数、外观、偏好与轨迹副本；不是云备份，卸载或清理缓存即丢失。

（七）diag: 本机诊断
1. diag:errors.v1：错误诊断日志，上限 20 条；含发生时间、错误类型、摘要、堆栈与页面路径，不主动记录输入内容。仅在未捕获异常、未处理 Promise 拒绝、页面丢失或内存告警时写入。

（八）本地临时文件
1. focus-bgm-v1.wav：全息专注运行时生成的 1 秒低振幅 WAV，约 16KB，仅用于后台计时保活。
2. 界面音效缓存：4 个内置极短 WAV 首次预加载时写入小程序本地文件目录，随小程序缓存清除。
3. 图片处理产生的临时文件、海报导出文件与快捷管道临时图片：仅存于小程序临时目录，由页面退出、系统清理或孤儿队列回收。

本小程序不长期保存任何图片内容、完整输入原文或搜索词；轨迹只保留摘要，天气只保留官方字段，专注只保留标签、时长、中断次数与等级等摘要。
清除方式：我的 → 清空工具数据（删除 tbx: 前缀数据，并清除 cyber: 快照中的轨迹副本）；数据驾驶舱可单条删除轨迹或清除快照中的轨迹副本；设置 → 存储与数据 → 清空专注数据（删除 focus: 数据）；气象站城市抽屉移除城市（删除该城市天气缓存）；微信 → 设置 → 通用 → 存储空间 → 小程序缓存；卸载小程序或清除小程序数据后，上述本地数据全部删除。


七、信息安全措施

1. 全链路本机处理：无自建服务器、无数据库，工具计算结果仅存在于本机内存与本机存储。
2. 网络最小化：仅全息气象按需请求 https://restapi.amap.com，全部 HTTPS；无广告、统计、推送请求。
3. 图片处理结束后删除中间临时文件，包括九宫格切片、压缩中间产物与水印导出临时文件；快捷管道产生的临时图片由孤儿队列在管道结束或下次启动时回收。
4. 诊断日志仅存本机，环形保留最近 20 条，单条消息截断 500 字符、堆栈截断 1000 字符。
5. 权限最小化：位置仅城市级模糊定位、相册仅写入、剪贴板仅按需读取；不申请相机、麦克风、通讯录等权限。
6. 密钥管理：高德 Web 服务 Key 仅具查询权限，通过构建期本地配置注入，不写入公开仓库，可在控制台随时停用。
