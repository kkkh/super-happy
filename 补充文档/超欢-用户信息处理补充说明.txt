一、小程序概况

超欢是一款以本机计算为主的效率工具与个人作品集。小程序不含账号体系、不提供登录、不接入自建后端；除「全息气象」「和风天气」「汇率换算」「元宝搜索」按需向对应公开数据服务发起请求外，其余功能不发起网络请求，计算与图片处理均在本机完成。

1. 名称：超欢（项目代号 chaohuan-toolbox）
2. 形态：主包 3 个页面（工具、收藏、我的）、9 个分包共 80 页、65 个工具、11 个作品条目、1 个全息专注页、1 个和风天气页
3. 运行模式：除在线天气、汇率与主动搜索外可离线使用；工具页、专注页、数据驾驶舱、简历与作品图集按微信分包机制按需下载
4. 账号：无注册、无登录、无用户 ID、无会员与付费功能
5. 联系方式：56967916@qq.com


二、处理的用户信息

依据《个人信息保护法》的最小必要原则，本小程序仅在下列场景、且由用户主动操作触发时处理信息；不存在后台自动采集。首次调用定位、相册等敏感能力前，统一通过 wx.requirePrivacyAuthorize 获取微信《用户隐私保护指引》授权；此外仅读取用于界面适配的运行环境参数（见 2.9）。

2.1 位置信息（城市级模糊定位）

触发场景：用户打开「全息气象」或「和风天气」，且同意微信《用户隐私保护指引》后。
调用接口：wx.getFuzzyLocation（type: gcj02）。
处理目的：获取城市级模糊位置；全息气象用于向高德逆地理编码换取 6 位 adcode 并请求当地天气，和风天气用于向 GeoAPI 反查所属城市并请求当地天气与天文数据。
处理方式：不申请精确 getLocation；经纬度仅用于当次逆地理 / GeoAPI 反查与本地日出日落计算，城市列表只保存城市级中心点（来自模糊定位、IP 区域中心或行政区数据）且和风天气最多保留两位小数，不保存设备精确坐标；不上传至自建服务器。
降级策略：拒绝授权、接口不可用或逆地理失败时，全息气象自动改用高德 IP 定位；和风天气回退默认城市或手动搜索 / 热门城市；IP 定位仍失败、为局域网、非法或无法识别的 IP 时，转为手动搜索城市。
权限声明：app.json 中 requiredPrivateInfos 仅声明 getFuzzyLocation；代码中不调用 wx.getLocation，不申请精确位置。首次调用前统一通过 wx.requirePrivacyAuthorize 获取微信《用户隐私保护指引》授权。

2.2 选中的图片

触发场景：图片压缩、图片取色、九宫格切图、水印工作台；用户点击「选择图片」后从相册选择。
调用接口：wx.chooseMedia（count: 1、mediaType: ["image"]、sourceType: ["album"]）。
处理方式：仅读取用户当次选择的一张图片，在本机内存与系统临时文件中处理；不上传、不写入小程序本地存储、不建立相册索引，中间文件在页面退出或重新选择时删除；若经快捷管道流转，图片会写入小程序临时目录，并在管道结束或下次启动时回收。
说明：sourceType 仅 album，不调用相机，不申请摄像头权限。

2.3 相册（仅写入）权限

触发场景：保存压缩图、九宫格切片、二维码、水印图、作品图集、个人名片或分享海报。
调用接口：wx.saveImageToPhotosAlbum（scope.writePhotosAlbum）。
处理方式：仅将用户指定的图片写入系统相册；不读取、不扫描、不遍历相册内容；拒绝授权时仅无法保存，不影响其他功能。

2.4 剪切板

写入：用户点击「复制」时调用 wx.setClipboardData，仅写入当次结果、邮箱或备份码。
读取：仅在「设置 → Sliced Transport」点击「从剪贴板追加」时调用 wx.getClipboardData 读取一次，用于跨端传输备份码。
处理方式：不后台读取、不监听剪贴板变化、不保存剪贴板内容。
授权：剪贴板读写均为微信隐私接口，首次使用需用户同意《用户隐私保护指引》；拒绝授权时不读取、不写入，仅提示授权后再试。

2.5 设备姿态（运动传感器）

触发场景：组件样板间的全息视差；全息专注的「翻转黑屏」（手机面朝下时自动黑屏）。
调用接口：wx.startDeviceMotionListening / wx.onDeviceMotionChange / wx.stopDeviceMotionListening。
触发条件：仅页面可见；视差在开启动效时监听；翻转黑屏仅在专注进行中且用户开启该开关时监听。
处理方式：设备姿态仅用于本地视觉阻尼或判断是否面朝下；离开页面、结束专注或组件销毁时立即停止并解绑；不保存原始传感器数据、不上传。
关闭方式：翻转黑屏可在专注设置关闭；视差可在「设置 → 动画强度」选择「省电」关闭。

2.6 屏幕亮度与常亮

触发场景：进入全息专注并开始计时。
调用接口：wx.getScreenBrightness、wx.setScreenBrightness、wx.setKeepScreenOn。
处理方式：进入专注时先读取当前屏幕亮度并记录原值，再临时调暗、保持屏幕常亮；退出页面、结束或放弃专注时恢复原亮度并关闭常亮；亮度原值与恢复标记仅存本机。
说明：不读取屏幕内容、不截屏、不录屏。

2.7 后台音频

触发场景：全息专注开启提示音且进入计时。
调用接口：wx.getBackgroundAudioManager、wx.getFileSystemManager。
处理方式：运行时生成 1 秒低振幅 WAV（focus-bgm-v1.wav，约 16KB）写入小程序本地文件目录并循环播放，用于避免锁屏后计时被系统中断；不录音、不申请麦克风、不播放任何第三方音频文件。
声明：app.json 中 requiredBackgroundModes 仅声明 audio。

2.8 振动与界面音效

触发场景：按钮点击、长按、完成或错误提示。
调用接口：wx.vibrateShort、wx.createInnerAudioContext。
处理方式：振动仅调用系统短振动；音效仅播放内嵌 WAV（首次预加载写入本地文件目录），不录音、不采集声音；可在「设置 → 物理震动」与「设置 → 系统音效」关闭。

2.9 运行环境参数

为实现外观跟随系统、响应式布局与画布清晰度适配，小程序只读取以下运行环境字段：
1. wx.getWindowInfo：windowWidth、windowHeight、statusBarHeight、pixelRatio 与 safeArea.bottom，用于页面布局、导航栏对齐、底部安全区与 Canvas 分辨率计算。
2. wx.getAppBaseInfo：theme，即系统深浅色，仅用于外观「跟随系统」模式。
3. wx.getDeviceInfo：platform，仅用于判断当前是否运行在开发者工具；基础库不支持该接口时回退 wx.getSystemInfoSync，同样只读取 platform。
4. wx.getMenuButtonBoundingClientRect：胶囊按钮位置，仅用于导航栏布局。
5. wx.getEnterOptionsSync：仅读取启动 query 中的 tool 参数，用于工具深链跳转；非法参数直接丢弃，不保存、不上传。
上述字段不包含设备型号、品牌、系统版本、序列号或任何设备唯一标识，不写入本地存储、不上传，也不与任何用户身份关联。系统深浅色在启动时读取一次，并通过 wx.onThemeChange 跟随系统变化更新。本小程序不采集 IMEI、OAID、IDFA、MAC 地址、Android ID 等设备标识。


三、网络请求与第三方服务

1. 第三方数据服务共四类：
   - 高德开放平台 Web 服务 API（https://restapi.amap.com）：全息气象；
   - 和风天气开发者 API（API Host 由开发者在构建期配置，域名以 *.qweatherapi.com 结尾）：和风天气；
   - 中国外汇交易中心（https://www.chinamoney.com.cn）：汇率换算官方中间价；
   - 腾讯云元宝搜索 WSA（https://wsa.tencentcloudapi.com 或 https://api.wsa.cloud.tencent.com）：元宝搜索。
2. 高德请求端点与用途：
   - /v3/weather/weatherInfo（extensions=base）：天气实况；
   - /v3/weather/weatherInfo（extensions=all）：4 天预报；
   - /v3/geocode/regeo：模糊经纬度转城市与 adcode；
   - /v3/ip：模糊定位不可用时的城市级 IP 定位；
   - /v3/config/district：城市搜索。
3. 和风天气请求覆盖已开通的 8 组 API、20 个接口与 27 个范围变体：GeoAPI 城市/热门/景点搜索与附近景点；实况、每日、逐小时预报 v1/v7；分钟降水；空气质量实时/小时/每日；天气预警；生活指数；日出日落、月相与太阳高度角；时光机历史天气。请求参数仅包含城市关键词、LocationID、城市级经纬度、日期、时间、语言与范围。
4. 汇率换算仅请求公开的人民币汇率中间价 JSON，不发送金额、币种选择或其他输入。
5. 元宝搜索仅在用户主动点击搜索时发送查询词、条数、时效、领域与站点筛选条件，不发送身份信息或本机存储内容。
6. 上述请求均不包含微信昵称、头像、手机号、OpenID/UnionID、通讯录、相册内容、剪贴板或其他工具的输入内容。
7. 传输安全：全部为 HTTPS；需在小程序后台配置对应 request 合法域名（发布前完成）。高德、和风天气、中国外汇交易中心与腾讯云可能按其隐私政策处理请求 IP、调用时间与请求参数；本程序不向其发送用户身份信息。高德隐私政策：https://lbs.amap.com/pages/privacy/；和风天气隐私政策：https://www.qweather.com/privacy/；腾讯云隐私政策：https://cloud.tencent.com/document/product/301/3011
8. 不接入广告、统计分析、推送、支付或社交分享 SDK；不进行数据出境，不存在境外接收方；不进行用户画像、广告定向或对用户权益有重大影响的自动化决策。
9. 密钥管理：高德 Web 服务 Key、和风天气 API KEY / JWT 与元宝搜索凭据均通过构建期本地配置注入，不写入公开仓库；和风天气凭据随小程序包发布，建议在控制台限制可用 API 与额度，泄露后可随时停用或更换。


四、不处理的信息

为避免歧义，本小程序明确不处理以下信息：

1. 身份与账号：姓名、微信昵称、微信头像、手机号、邮箱（邮箱仅作为开发者联系方式对外公示，不从小程序内收集）、身份证号码、实名信息、登录凭证、OpenID/UnionID。
2. 设备标识：IMEI、OAID、IDFA、MAC 地址、Android ID、序列号等任何设备唯一标识。
3. 媒体与传感器原始数据：摄像头画面、麦克风录音、相册全量内容、通讯录、通话记录、日历、蓝牙、健康数据、微信运动步数；设备姿态仅用于本地视觉阻尼，不留存原始数据。
4. 业务与内容：订单信息、发票信息、发布内容、所关注账号、操作日志、车牌号。
5. 剪贴板历史：仅在用户点击「从剪贴板追加」时读取一次，不保留、不统计。


五、权限申请与撤回

本小程序涉及的敏感能力与权限如下：

1. 位置信息（城市级模糊定位）：仅在全息气象与和风天气中申请；未授权时自动降级为 IP 定位 / 手动选城或默认城市，不影响其他工具。
2. 保存到相册（scope.writePhotosAlbum）：仅在用户点击保存时申请；未授权时仅无法保存图片。
3. 剪切板读取：仅在用户点击「从剪贴板追加」时读取一次，用于导入备份码，不后台读取、不保存剪贴板内容。
4. 设备姿态：全息视差在支持视差的页面开启；翻转黑屏仅在专注进行中且开关开启时监听；均可在对应设置中关闭。
5. 后台音频：仅在全息专注计时期间使用，可随时关闭提示音或退出专注。

撤回路径：微信 → 设置 → 小程序 → 超欢 → 权限管理，关闭「位置信息」或「保存到相册」；隐私授权可在小程序内重新触发，或在微信「设置 → 隐私 → 授权管理」中管理。
撤回影响：撤回位置后气象站与和风天气改用 IP 定位 / 手动选城或默认城市；撤回相册后再次保存会引导前往设置页重新开启或放弃保存；其余工具不受影响。


六、本机数据与存储

为记住常用工具、天气城市、专注记录并定位本机异常，本小程序使用微信本地存储与本地文件目录保存以下轻量数据。数据仅保存在用户设备内，不离开设备、不上传服务器。

（一）tbx: 工具命名空间
1. tbx:recent / tbx:recent.at：最近使用的工具 id（上限 12）与时间戳，仅用于自动清理。
2. tbx:favorites：收藏的工具 id，上限 100 项。
3. tbx:usage：累计打开工具的次数（单个整数），仅用于首页数字看板。
4. tbx:history：本机计算轨迹摘要，上限 100 条；含工具名称、时间、输入/输出摘要与主题快照。
5. tbx:draft.*：最近一次工具输入与模式，仅存本机，单工具 ≤4KB，最多 20 个，30 天自动清理；敏感工具不保存。
6. tbx:workflow.pipes：快捷管道 A → B 的工具配对与成功流转次数，上限 6 条。
7. tbx:workflow.garbage：待回收的临时图片路径队列，仅存路径，不含图片内容。
8. tbx:searchHistory：本机搜索历史，上限 8 条，仅含关键词文本。
9. tbx:fx.official.v1：最近一次中国外汇交易中心人民币汇率中间价与更新时间，仅用于离线回退。
10. tbx:helpBannerDismissed：首页帮助横幅的关闭状态（布尔值）。
11. tbx:prefs、tbx:ack.finance.v1、tbx:ack.health.v1、tbx:legacy-tip、tbx:legacy-tip-home：旧版偏好（仅升级读取）与金融、健康、收藏提示的确认/关闭状态。

（二）app: 全局偏好
1. app:prefs.v1：震动、音效、光效、动画、字号与自动清理天数；app:prefs.v0 仅在升级时读取一次。
2. app:storage.version：本地数据版本号，仅用于升级迁移。
3. app:privacy.version：已确认的隐私保护指引版本（当前 v2），仅在「重置全部本机数据」时清除。
4. app:backup.at：最近一次备份导出的时间戳，仅用于设置页展示；删除备份文件时同步清除。
5. hasPendingUpdate：更新提示红点标记（布尔值，无命名空间），更新生效或确认无更新后自动清除。

（三）gallery. 外观与作品
1. gallery.theme.mode：白昼 / 夜航 / 跟随系统。
2. gallery.works.favorites：作品收藏 id，上限 200 项。
3. gallery.glass.meta：Spatial Glass 界面元数据，含版本号、迁移时间、外观模式与环境预设。

（四）weather: 气象缓存
1. weather:cities:v1：城市列表，上限 5 个；含城市名、省份、6 位 adcode、城市级中心点、来源标记与更新时间。
2. weather:current:v1：当前选中城市的 adcode。
3. weather:live:v1:{adcode} / weather:forecast:v1:{adcode}：实况与 4 天预报缓存，分别 15 / 30 分钟过期。
4. weather:fail:v1:{adcode}:{kind}：请求失败负缓存，60 秒过期。
5. weather:ambient:v1、weather:lab:v1、weather:manual-refresh:v1：环境音开关、实验开关与上次手动刷新时间。

（五）qweather: 和风天气
1. qweather:cities:v1：保存的城市，上限 5 个；含城市名、行政区、LocationID、城市级中心点（最多两位小数）、时区与来源标记。
2. qweather:current:v1：当前选中城市的标识。
3. qweather:cache:v2：接口结果缓存，单键最多 40 条、总量按 650KB 上限淘汰最旧项；按官方 TTL（实况 10 分钟、逐小时 30 分钟、每日 2 小时、预警 10 分钟、指数 6 小时、分钟降水 5 分钟、空气 30–480 分钟、天文 6 小时、历史 24 小时），跨本地自然日失效；Geo 搜索结果只在会话内使用，不落盘。
4. 旧版 qweather:cache:v1 在升级后清理，不再写入。

（六）focus: 全息专注
1. focus:session:v1 / focus:prefs:v1：当前会话与偏好（含可选标签、阶段、轮次、音频与翻转检测开关）。
2. focus:ledger:v1：专注记录，上限 50 条；含可选标签、起止时间、专注时长、中断次数、等级与校验签名。
3. focus:stats:v1 / focus:key:v1 / focus:brightness:v1：累计统计、本机校验密钥与亮度恢复标记。
上述数据只存本机、不上传；可在「设置 → 存储与数据 → 清空专注数据」删除。

（七）cyber: 时间旅行与热备
1. cyber:auto:v1 / cyber:hot:v1：自动快照（最多 5 个）与手动热备（最多 3 个），含当时收藏、最近使用、打开次数、外观、偏好与轨迹副本。
2. cyber:frames:v1：时间轴最近 8 帧状态，仅用于选帧回滚。
3. cyber:pilot:v1：自动任务开关与表达式。
快照不是云备份，卸载或清理缓存即丢失。

（八）diag: 本机诊断
1. diag:errors.v1：错误诊断日志，上限 20 条；含发生时间、错误类型、摘要、堆栈与页面路径，不主动记录输入内容。

（九）toolbox: 其他
1. toolbox:meeting-timer.hud.v1：会议倒计时悬浮胶囊在屏幕上的位置（left / top），仅用于恢复位置。

（十）本地文件
1. focus-bgm-v1.wav：专注后台提示音，约 16KB，1 秒低振幅。
2. 界面音效缓存：4 个极短 WAV，首次预加载时写入。

七、信息安全措施

1. 全链路本机处理：无自建服务器、无数据库，工具计算结果仅存在于本机内存与本机存储。
2. 网络最小化：仅全息气象、和风天气、汇率换算与元宝搜索按需请求对应公开数据服务，全部 HTTPS；无广告、统计、推送请求。
3. 图片处理结束后删除中间临时文件，包括九宫格切片、压缩中间产物与水印导出临时文件；快捷管道产生的临时图片由孤儿队列在管道结束或下次启动时回收。
4. 诊断日志仅存本机，环形保留最近 20 条，单条消息截断 500 字符、堆栈截断 1000 字符。
5. 权限最小化：位置仅城市级模糊定位、相册仅写入、剪贴板仅按需读取；不申请相机、麦克风、通讯录等权限。
6. 密钥管理：高德 Web 服务 Key、和风天气凭据与元宝搜索凭据仅通过构建期本地配置注入，不写入公开仓库；和风天气凭据随包发布，可控制台限制 API 与额度，泄露后可随时停用。
7. 本地缓存治理：设置中心通过 wx.getStorageInfoSync 读取本机缓存键数量与占用大小用于展示；启动时按偏好裁剪 tbx:recent 与时间戳。不读取缓存内容、不上报。
